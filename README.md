# Портфель · 3D — прототип визуализации

Интерактивная 3D-визуализация инвестиционного портфеля из 10 инструментов.
Портфель представлен кубом, разбитым на блоки, объём каждого блока строго
пропорционален доле инструмента в портфеле.

## Как запустить

Просто откройте `index.html` двойным кликом (Chrome / Edge / Firefox).
Сервер и установка зависимостей не нужны — Three.js лежит локально в `vendor/`.

## Управление

| Действие | Результат |
|---|---|
| Перетаскивание фона | Вращение всего куба (камера) |
| Клик по кубу | Разбор на отдельные блоки |
| Перетаскивание блока (после разбора) | Вращение **только этого** блока |
| Клик по пустоте (после разбора) | Собрать куб обратно |
| Колесо мыши | Масштаб |
| `Space` | Разобрать / собрать |
| `R` | Сбросить камеру |
| Наведение на блок / строку списка | Подсветка инструмента |

На гранях каждого блока: логотип-эмитент, тикер, название, **цена акции**,
дневное изменение и доля в портфеле.

## Мобильные устройства

Вёрстка адаптивная, отдельные правила для планшетов (≤900px) и телефонов (≤720px):

- верхняя сводка переносится в компактную строку под логотипом;
- список инструментов превращается в **bottom-sheet**, который выезжает снизу, с затемнением (тап по фону закрывает);
- кнопка «Состав» и главная кнопка образуют единую нижнюю панель — удобно нажимать большим пальцем;
- учтены «безопасные зоны» (`env(safe-area-inset-*)`) под чёлку и домашний индикатор;
- на тач-экранах отключены hover-подсказки (тултип показывается только при наличии мыши), а тап по блоку его подсвечивает;
- камера на телефоне отодвигается и поднимает куб над нижней панелью, разлёт блоков делается компактнее, а плотность пикселей ограничена ради плавности;
- в ландшафте подсказка скрывается, панель получает больше высоты.

## Как устроено

- **Разбиение куба.** Рекурсивный алгоритм делит куб по самой длинной оси на
  две группы, подбирая инструменты так, чтобы суммы весов были равны. В итоге
  объём каждого блока точно равен `вес / 100` от объёма куба (проверено: сумма
  100%, блоки заполняют куб без пустот и пересечений).
- **Грани.** Текстуры рисуются на `<canvas>` и натягиваются на все 6 граней
  блока (`CanvasTexture`), поэтому каждая сторона несёт логотип и цену.
- **Разбор.** Блоки плавно разъезжаются вдоль радиусов; после разбора включается
  режим индивидуального вращения (raycasting определяет, какой блок схвачен).

## Как изменить данные

Все инструменты — в начале `app.js` в массиве `INSTRUMENTS`:

```js
{ ticker:'AAPL', name:'Apple', weight:18, price:245.30, change:1.24,
  color:'#A2AAB3', logo:'AA' }
```

`weight` — доля в портфеле в процентах (сумма должна давать примерно 100),
`price` — цена акции, `change` — дневное изменение, `color`/`logo` — оформление
грани. Всё остальное (размеры блоков, список, сводка) пересчитывается само.

## Дизайн

Направление — **dark-tech finance terminal** (по референсу): глубокий navy,
холодный off-white, один акцент — electric-cyan, техническая сетка, hairline-структура.
Типографика: **Manrope** (UI) + **JetBrains Mono** (все числа). Шрифты лежат
локально, поэтому страница работает офлайн.

Сегменты куба — **глянцевое «стекло»**: скруглённые рёбра, clearcoat-покрытие,
отражения из процедурной env-map и fresnel-свечение по контуру в цвете
инструмента. Верхняя грань — светящаяся «крышка», боковые — карточка с
логотипом и ценой.

Вращение **вязкое и инертное**: камера и блоки двигаются с ощутимым усилием и
продолжают вращаться по инерции после отпускания (в блоке — с затуханием).
Учтены `prefers-reduced-motion` (инерция и автоповорот отключаются) и
`prefers-reduced-transparency`.
